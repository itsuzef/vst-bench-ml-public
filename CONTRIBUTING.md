# Contributing

Use this repository's Issues for questions and reproducible bug reports, and
pull requests for source or documentation improvements. This is the maintained
public source for `vst-bench-ml`. Include your software version, operating system,
Python version, command, expected result, and observed result.

Use the sample-free companion fixture for examples where possible. Only include
material you have permission to share. See [development and release checks](docs/RELEASE.md).
MIT applies to source contributions. No response-time or maintenance-duration
commitment is made.
